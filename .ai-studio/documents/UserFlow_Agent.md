# User Flow — Agent

## Role Summary
The Agent handles day-to-day complaint resolution: reviewing AI-generated recommendations, validating them at a glance, and sending responses or taking action on assigned complaints.

---

## Flow

### 1. Access
- Agent logs in with Agent-level role permissions.
- Lands on the **Agent Dashboard**.

### 2. View Assigned Complaints
- Dashboard displays complaints assigned to the Agent (or their department), each showing:
  - Complaint category
  - Priority
  - Sentiment
  - GenAI recommendation
  - Validation status (Verified / Manual Review pending)
  - Suggested response
  - Escalation warnings (if any)

### 3. Open a Complaint
- Agent selects a complaint to view full detail:
  - Complaint Intelligence output (issue, category, subcategory, entities, sentiment, urgency, priority)
  - Recommended department/routing
  - Resolution steps generated by Pipeline 1
  - Verification status from Pipeline 2 (matched / mismatched fields, with explanation)
  - Referenced policy sections (with source traceability)

### 4. Review the AI-Generated Response
- Agent reads the drafted professional customer response.
- Checks resolution steps and any flagged issues:
  - Unsupported promise flags
  - Hallucination flags
  - Escalation flags

### 5. Take Action
Depending on validation status:

**If Verified:**
- Agent reviews the response for tone/accuracy.
- Sends the response to the Customer.
- Marks complaint status as **In Progress** or **Resolved**.

**If Flagged for Manual Review:**
- Agent cannot send the response directly.
- Complaint is routed to the Reviewer queue (or Agent escalates it themselves if authorized).

### 6. Handle Escalation
- If escalation is required (per Pipeline 2's independent check), the Agent:
  - Reviews auto-generated escalation notes (complaint summary, key facts, reason, actions taken, relevant policy, next action)
  - Forwards to the appropriate escalation level (Supervisor Review, Department Manager, Specialist Team, Compliance Review, Critical Management Escalation)

### 7. Follow-Up Management
- Agent reviews follow-up requirements (e.g., "request additional information," "refund-status update," "resolution confirmation").
- Schedules or sends follow-up communication as needed.
- Updates SLA tracking status.

### 8. Update Complaint Status
- Agent progresses the complaint through its lifecycle:
  New → Analyzed → Assigned → In Progress → Awaiting Customer → Escalated → Resolved → Closed → Reopened

### 9. Handle Repeat/Duplicate Complaints
- If flagged as a repeat or duplicate, Agent reviews complaint history and links records appropriately, adjusting priority if needed.

### 10. Monitor SLA
- Agent dashboard flags complaints approaching SLA deadlines (SLA Risk Detection) so the Agent can prioritize accordingly.

---

## Key Guarantees for the Agent
- The Agent never has to manually determine department routing, urgency, or policy applicability from scratch — the system provides a verified recommendation.
- Any AI recommendation the Agent sees has already been checked against the Complaint Resolution Rule Matrix.
- The Agent is explicitly warned before sending anything containing an unsupported promise or unverified escalation status.
